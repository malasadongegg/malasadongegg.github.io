# Mark's Commit Log

A git-log-styled portfolio: a single static `index.html` with a timeline of projects, a light/dark theme toggle, and sort/visibility filters.

## Editing

Projects live in the `projects` array at the bottom of `index.html`. Add an entry with `date`, `name`, `status`, `kind`, `description`, `tags`, `repo`, and optionally `live` and `download`.

Screenshots go in `screenshots/`.

## Hosting

Served by GitHub Pages from `main`.
